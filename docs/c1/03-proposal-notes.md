# C1 기획서용 정리

2026-11-12 기준. Pleos Connect 에뮬레이터 v2.1.0, 브랜치 `jaegyun/c1-appgraph-start`.

표시 규칙

- **구현**: 에뮬레이터에서 동작을 직접 확인한 것
- **설계**: 코드와 단위 테스트는 있지만 에뮬레이터에서 확인하지 못한 것
- **시연용 신호**: SDK가 아니라 디버그 패널의 가짜 차량 값으로 보여 주는 것

## 1. C1 범위와 신호 경로

C1은 차량 경고등이 켜지면 의미·심각도·조치를 한국어 음성으로 먼저 알리고, 정차하면 조치 단계를 화면에 보여 줍니다.

```
Virtual Console ─> Pleos Vehicle SDK registerTelltales ─> PleosWarningSource ─> WarningSource 포트
                                                                                   │
                AAOS 기어·주행 규제 ─> CarDriveStateSource ─> DriveRuntime ────────┤
                                                                                   ▼
                                      WarningAnnouncer ─> SpeechOutput 포트 ─> Pleos TextToSpeech SDK (ON_DEVICE)
                                      WarningScreen (주행 중 카드 / 정차 후 조치)
```

### 동작별 상태

| 동작 | 상태 | 근거 |
|---|---|---|
| 경고등 구독: `registerTelltales`로 켜짐·깜빡임·꺼짐 수신, 약 0.1초 이내 | 구현 | `01-probe-results.md` |
| `PRIVATE_CAR_SAFETY` 권한: 매니페스트 선언만으로 부여(보호 수준 normal) | 구현 | `dumpsys package` |
| 경고등 11종 → 경고 10종 연결(공기압, 주차 브레이크 2종, 조향 보조, ABS, ESC, ESC 꺼짐, 전기차 시스템, 출력 제한, 12V 배터리, 에어백) | 구현 | `c1_all_warnings.json` 재생 |
| 두 경고가 함께 켜진 경우 | 구현 | 콘솔로 TPMS + ABS 확인 |
| 기어·주행 규제가 콘솔 기어를 따라감 | 구현 | Step 1 |
| 한국어 음성: Pleos TextToSpeech SDK 3.3.1, ON_DEVICE, `Locale.KOREA` | 구현 | SDK 이벤트 onStart → onDone, 약 7초 |
| 문장마다 오디오 포커스 요청·반납(`GAIN_TRANSIENT_MAY_DUCK`, 주행 안내 usage) | 구현 | 시스템 로그 `AUDIOFOCUS_REQUEST_GRANTED`, abandon |
| 포커스 상실 처리: LOSS 즉시 중지, LOSS_TRANSIENT 중지 후 한 번 다시 말하기 | 설계 | 단위 테스트만. 다른 오디오 앱과의 실제 경합은 미확인 |
| `LOSS_TRANSIENT_CAN_DUCK`에서 음량 낮추기 | 미지원 | SDK에 음량 조절이 없어 그대로 말함 |
| 우선순위: 높은 우선순위가 낮은 문장을 끊음, 같거나 낮으면 대기 | 설계 | 단위 테스트만. 지금 포트를 쓰는 기능은 C1뿐 |
| 다른 화면이 열려 있어도 음성 안내 | 구현 | A3 미러 화면에서 리허설 |
| 다른 앱(설정)이 앞에 있어도 경고 수신·음성 안내 | 구현 | 앱 프로세스가 살아 있는 동안. 시스템이 프로세스를 종료한 뒤는 미확인 |
| 주행 중: 심각도 색 카드, 스크롤·애니메이션·터치 없음 | 구현 | 콘솔 기어 D |
| 정차 시 C1 화면으로 자동 전환 | 구현 | `c1_tpms.json` 리허설 |
| 정차 후: 조치 단계, 다시 듣기, 진입 애니메이션(한 번) | 구현 | 리허설, 화면 캡처 |
| 시스템 애니메이션 배율 0이면 애니메이션 생략 | 설계 | 단위 테스트만 |
| 경고가 꺼지면 말하던 문장 중지 | 구현 | SDK 이벤트 onStop |
| 주차 브레이크 경고는 P가 아닐 때만 안내 | 구현 | 콘솔 P/D 전환 |
| 심각도 색(위험 빨강, 주의 주황, 정보 파랑), 글자 대비 4.5:1 이상 | 구현 | 화면 캡처, 대비 테스트 |
| 브레이크액·워셔액 경고 안내 | 시연용 신호 | 콘솔에 경고등 없음, SDK API는 에뮬레이터 미지원 |
| 엔진·엔진오일·안전벨트 경고 안내 | 시연용 신호 | 콘솔 경고등은 있으나 연결하지 않음 |
| 디버그 패널 시나리오 `c1_warning`, `c1_tpms_demo` | 시연용 신호 | 가짜 차량 |

차량 값은 실제 차량이 아니라 에뮬레이터의 Pleos Connect Virtual Console이 만듭니다. 시연은 `tools/console/console.py`로 콘솔을 조종해 같은 순서를 매번 재생합니다. 이 스크립트는 공개 문서에 없는 콘솔 내부 API를 쓰며 에뮬레이터 v2.1.0에서만 확인했습니다. 앱에는 포함되지 않습니다.

## 2. 향후 계획

공개 SDK와 에뮬레이터가 지금 지원하지 않는 것만 적습니다.

| 항목 | 지금 | 계획 |
|---|---|---|
| 덕킹 시 음량 낮추기 | TextToSpeech SDK에 음량 조절 없음 | SDK가 지원하면 `PleosSpeechOutput`의 `duck()`에서 처리 |
| 브레이크액·워셔액·엔진오일 레벨 경고 | 전용 Safety API가 에뮬레이터에서 `ERROR_NOT_SUPPORTED_PROPERTY` | 지원되는 환경에서 `PleosWarningSource`에 연결 |
| 안전벨트·엔진·엔진오일 압력 경고등 | Telltale로 받을 수 있으나 연결하지 않음 | 문구를 확정한 뒤 추가(매핑 표에 한 줄) |
| 실차의 `PRIVATE_CAR_SAFETY` | 에뮬레이터에서는 선언만으로 부여. 실차 정책은 미확인 | 실차 심사 기준 확인 |
| 앱 프로세스가 종료된 상태의 경고 감시 | 포그라운드 서비스 없음 | 필요하면 주행 중 상주 방식 검토 |
| 차종별 조치 문구 | 일반 문구 초안 | 공식 매뉴얼과 대조해 확정(4장) |
| 정차 판단 | 기어 P 기준. D에서 멈춘 경우는 주행으로 봄 | 속도 신호를 함께 쓰는 방안 검토 |

## 4. 팀 PRD에서 고칠 내용

1. **Telltale 권한**: "주최 측이 PRIVATE 권한을 제공"이라는 전제 대신 "에뮬레이터 v2.1.0에서는 `PRIVATE_CAR_SAFETY`를 선언만 하면 부여되고 `registerTelltales`가 동작함(11/12 확인)"으로 고칩니다. 실차 정책은 미확인으로 둡니다.
2. **C1의 "미시험" 표시**: Telltale 구독, 콘솔 Telltales 변화 수신, 기어·주행 규제(`CarUxRestrictions`)가 콘솔 조작을 따라가는지는 모두 확인했습니다. README "다음 단계"의 주행 규제 시험 항목도 완료입니다.
3. **음성**: "Pleos TTS는 Coming Soon이라 표준 TTS 사용"을 "Pleos TextToSpeech SDK 3.3.1 ON_DEVICE 사용, 로캘은 `Locale.KOREA`(`ko`만 주면 오류), 에뮬레이터에 Android 표준 TTS 엔진 없음"으로 고칩니다. 권한 이름 `pleos.car.permission.TTS_SERVICE`도 확인됐습니다.
4. **C1 경고 범위**: "우선 TPMS"에서 초보 운전자 기준 10종으로 넓어졌습니다. 시연의 중심은 여전히 TPMS입니다.
5. **전용 Safety API**: `hasPowerDownWarningIndicator`, `hasSeatAirbagEnabled`는 콘솔 경고등을 따라가지 않고, 안전벨트·엔진오일·브레이크액·워셔액 API는 에뮬레이터에서 지원되지 않습니다. C1은 Telltale만 씁니다.
6. **디자인 룰**: 5색 규칙에 예외가 생겼습니다. 경고 심각도 표시에만 빨강(#B3261E)과 주황(#E8710A)을 씁니다. 미결 항목 "위험 경고에 별도 경고색을 허용할까?"를 이 내용으로 확정해야 합니다.
7. **공유 파일 변경**: `WarningType`에 8종 추가, `AppGraph`의 경고 안내 시작과 화면 전환 요청, `MainActivity`의 화면 전환 수신, 디버그 패널의 "C1 시연 준비" 버튼, TextToSpeech 의존성 추가. PR에서 후의 리뷰가 필요합니다.
8. **말하기 포트 담당**: `PleosSpeechOutput.kt`(담당 "E2 담당")를 C1이 채웠습니다. B1·E2가 같은 포트를 쓸 때의 우선순위 규칙(경고가 일반 안내를 끊음)을 함께 확인해야 합니다.

## 6. 규칙 점검에서 남은 것

| 항목 | 내용 |
|---|---|
| 주행 중 "카드 한 장" | C1 화면을 열어 둔 채 주행하면 경고 카드 외에 심각도 개수 배지와 "정차 후에 자세히 볼 수 있어요" 안내가 함께 보입니다. 모두 정적이고 터치가 필요 없지만 "한 장"은 아닙니다. 카드에는 한 문장이 아니라 경고 제목이 나옵니다 |
| 위험 경고가 주의 문장을 끊지 않음 | C1 경고는 모두 같은 우선순위(WARNING)라, 주의 문장이 재생 중이면 위험 문장은 그 뒤에 나옵니다 |
| "급정지하지 말고"로 시작하는 문장 | 기존 테스트가 모든 음성 문장에 요구합니다. ABS·출력 제한·12V 배터리에서는 어색할 수 있습니다 |
| 기어를 모를 때 | 주행으로 보므로 주차 브레이크 경고도 안내합니다 |
| 애니메이션 배율 | 화면을 열 때 한 번 읽습니다. 화면이 열린 채 설정을 바꾸면 다음에 열 때 반영됩니다 |
| `INTERNET` 권한 | TextToSpeech SDK가 넣습니다. ON_DEVICE 모드에서 C1은 네트워크를 쓰지 않습니다 |
| 덕킹 | 2장 참고 |
