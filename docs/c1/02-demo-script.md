# C1 시연 스크립트 (PRD 시나리오 3: 주행 중 공기압 경고)

2026-11-12 리허설 기준. Pleos Connect 에뮬레이터 v2.1.0, Virtual Console 사용. 전체 약 30초.

## 준비

1. 에뮬레이터를 켜고 포트를 연결합니다: `adb forward tcp:8088 tcp:8088`
2. 브라우저에서 `http://127.0.0.1:8088` (Virtual Console)을 열어 둡니다. 시연이 끝날 때까지 닫지 않고, 재생 중에는 콘솔 화면을 직접 조작하지 않습니다.
3. 앱(debug 빌드)을 실행하고 **디버그** 메뉴의 "포트 연결"에서 세 개를 **실제**로 바꿉니다.
   - 주행 상태
   - 경고
   - 음성 말하기
4. 보여 주고 싶은 화면으로 이동합니다. 다른 화면(예: **A3 미러**)에서 시작하면 정차할 때 C1 화면으로 자동 전환되는 것까지 보여 줄 수 있습니다.
5. 콘솔이 주차(P), 속도 0, 경고등 모두 꺼짐인지 확인합니다: `python3 console.py state`

## 실행

```
cd tools/console
python3 console.py run scenarios/c1_tpms.json
```

## 단계별 기대 결과

시각은 명령을 실행한 뒤 흐른 시간입니다.

| 시각 | 콘솔 동작 | 음성 | 앱 화면 |
|---|---|---|---|
| 0초 | 기어 D, 속도 30 km/h | 없음 | 보고 있던 화면이 주행 상태로 바뀜 (A3 미러: "정차 후에 자세히 볼 수 있어요") |
| 3초 | TPMS 경고등 켜짐 | "주의 경고예요. 타이어 공기압이 낮을 수 있어요. 급정지하지 말고 다음 휴게소나 목적지에서 점검해 주세요." (약 7초) | 다른 화면이면 그대로. C1 화면이면 주황색 카드 "주의 경고 · 타이어 공기압 경고"와 "정차 후에 자세히 볼 수 있어요" |
| 3~14초 | 속도 30 km/h 유지 | 10초쯤 문장이 끝남 | 변화 없음. 스크롤·애니메이션 없음 |
| 14초 | 속도 0, 기어 P | 없음 | **C1 경고 화면으로 자동 전환.** 주황색 줄의 "타이어 공기압 경고" 카드. 경고등 아이콘이 세 번 깜빡이고 조치 단계 4개가 차례로 나타남. "다시 듣기" 버튼 |
| 26초 | TPMS 경고등 꺼짐 | 없음 | 카드가 사라지고 "확인된 경고가 없어요" |

정차 후 화면의 조치 단계:

1. 타이어가 눈에 띄게 주저앉았는지 확인해 주세요.
2. 타이어가 주저앉았거나 손상돼 보이면 운전하지 말고 긴급출동에 연락해 주세요.
3. 차량 매뉴얼의 적정 공기압을 확인해 보충해 주세요.
4. 경고가 계속 켜지면 서비스센터에서 점검받아 주세요.

에뮬레이터 왼쪽 계기판 영역에는 빨간 TPMS 경고등 아이콘이 함께 켜집니다. 에뮬레이터가 따로 띄우는 알림 카드는 없습니다.

## 덧붙여 보여 줄 수 있는 것

- **다시 듣기**: 14~26초 사이에 버튼을 누르면 같은 문장을 한 번 더 말합니다.
- **말하는 중 해제**: `python3 console.py telltale TPMS On` 후 2초 안에 `telltale TPMS Off`를 하면 문장이 바로 멈춥니다.
- **심각도 색**: `telltale MDPS On`(위험, 빨강), `telltale TPMS On`(주의, 주황), `telltale ESCOff On`(정보, 파랑). 정보는 주행 중 카드와 음성이 없습니다.
- **모든 경고 훑어보기**: `python3 console.py run scenarios/c1_all_warnings.json` (약 95초, 본 시연용 아님).

## 실제 신호와 시연용 신호

본 시연(`c1_tpms.json`)에서 앱이 받는 값은 모두 SDK를 거친 실제 신호입니다. 실제 차량이 아니라 에뮬레이터의 Virtual Console이 차량 값을 만들어 냅니다.

| 값 | 앱이 받는 경로 | 구분 |
|---|---|---|
| 기어 | AAOS Car API `GEAR_SELECTION` | 실제 신호 |
| 주행 규제 | AAOS `CarUxRestrictions` | 실제 신호 |
| 경고등 (TPMS 등) | Pleos Vehicle SDK `registerTelltales` | 실제 신호 |
| 음성 | Pleos TextToSpeech SDK 3.3.1, ON_DEVICE | 실제 출력 |

콘솔로 켤 수 있는 경고: 타이어 공기압, 주차 브레이크, 조향 보조(MDPS), ABS, ESC, ESC 꺼짐, 전기차 시스템, 출력 제한, 12V 배터리, 에어백.

디버그 패널로만 보여 줄 수 있는 경고(시연용 신호, 화면에 "시연 신호"로 표시됨):

- 브레이크액, 워셔액: 콘솔에 조작 항목이 없고 에뮬레이터가 해당 SDK API를 지원하지 않습니다.
- 엔진, 엔진오일, 안전벨트: 콘솔에 경고등은 있지만 앱에 연결하지 않았습니다.

디버그 패널의 `c1_tpms_demo` 시나리오는 콘솔 없이 같은 흐름을 가짜 차량으로 재생합니다. 이때 "경고"와 "주행 상태"는 **가짜**로 둡니다.

## 알아 둘 점

- 콘솔 페이지가 닫혀 있으면 스크립트가 아무것도 보내지 않고 안내 문구만 출력합니다.
- 콘솔은 가속 페달이 0이면 속도를 초당 약 2 km/h씩 줄입니다. 그래서 시나리오가 3~4초마다 30 km/h를 다시 보냅니다. 계기판 속도가 30 → 23 → 30처럼 조금 흔들립니다.
- 오류가 나거나 Ctrl-C로 멈추면 스크립트가 속도 0, 기어 P, 켠 경고등 끄기를 한 번 시도합니다.
- 콘솔 API는 공개 문서에 없는 내부 API라 에뮬레이터 v2.1.0에서만 확인했습니다.
- 포트 연결 설정은 앱을 다시 시작하면 모두 가짜로 돌아갑니다. 시연 전에 다시 바꿉니다.
