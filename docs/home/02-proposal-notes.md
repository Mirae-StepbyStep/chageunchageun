# 홈 · 첫 실행 · 앱 아이콘 기획서용 정리

2026-11-13 기준. Pleos Connect 에뮬레이터 v2.1.0(2560×1440, 160dpi, 가로, 밝은 배색), 브랜치 `jaegyoon/home-firstrun`.

표시 규칙

- **구현**: 에뮬레이터에서 동작을 직접 확인한 것. 근거 화면은 `docs/home/screenshots/`에 있습니다.
- **설계**: 코드와 단위 테스트는 있지만 에뮬레이터에서 확인하지 못한 것
- **시연용 신호**: SDK가 아니라 디버그 패널의 가짜 차량 값(기어, 경고)으로 확인한 것

## 1. 한눈에 보기

- 앱을 처음 켜면 **첫 실행** 화면이 열려 두 가지만 묻습니다: 위치 사용 동의, 안내 깊이(자세히·보통·간단히).
- **홈**은 정차 중에는 출발 전에 할 일(미러 맞추기, 조작 연습), 지금 켜진 경고, 내 설정을 한 화면에 보여 줍니다.
- 주행 중에는 홈이 한 문장과 경고 카드 한 장만 남기고, 설정 화면은 숨깁니다. 화면 조작을 요구하지 않습니다.
- 앱 아이콘은 멀어질수록 짧아지는 차선과 그 앞의 한 점으로 "한 칸씩 익숙해지는 운전"을 나타냅니다.

## 2. 첫 실행

세 단계이고 화면 위에 "1 / 3" 진행 표시가 있습니다. 이전 단계로 돌아갈 수 있습니다.

| 단계 | 내용 |
|---|---|
| 1/3 위치 사용 | "위치 정보를 사용할까요?" [동의해요] [나중에 할게요] |
| 2/3 안내 깊이 | 자세히(기본) · 보통 · 간단히 중 하나를 고름. "경고 안내는 레벨과 관계없이 항상 자세히 알려드려요." |
| 3/3 준비 완료 | 고른 내용 요약. [미러부터 맞춰볼까요?] → 미러 맞추기(A3), [홈으로] |

| 동작 | 상태 | 근거 |
|---|---|---|
| 새로 설치한 앱을 켜면 첫 실행 화면에서 시작 | 구현 | `6c-onboarding-step1.png`, 새로 설치해 3회 확인 |
| 세 단계 진행, 요약 화면, [홈으로] | 구현 | `6c-onboarding-step1.png`, `6e-onboarding-step3.png` |
| 선택 표시: 테두리 + ✓ + "선택됨" 글자(색만으로 구분하지 않음) | 구현 | `5c-change-opens-settings.png` |
| 설정이 앱을 다시 켜도 유지되고, 두 번째 실행부터는 홈에서 시작 | 구현 | 완료 후 다시 실행해 확인 |
| 완료 후 같은 화면이 "내 설정" 편집 화면으로 열림(홈의 [바꾸기]) | 구현 | `5c-change-opens-settings.png` |
| [미러부터 맞춰볼까요?]가 미러 맞추기를 엶 | 설계 | 단위 테스트 없음. 홈의 [미러 맞추기]와 같은 경로이며 그쪽은 확인함 |
| 주행 중에는 "정차하면 처음 설정을 이어서 할게요." 한 문장만 보이고, 정차하면 같은 단계·같은 선택으로 돌아옴 | 설계 | 단위 테스트만 |
| 주행 중에 앱을 켜면 첫 실행 대신 홈에 머묾 | 설계 | 미확인 |

## 3. 안내 깊이 (어드바이저 레벨)

PRD 미결 "몇 단계로 두고 어디서 고를까"에 대한 제안입니다: **3단계, 첫 실행과 홈의 [바꾸기]에서 고름.**

| 레벨 | 화면 문구 | E1·A5에 넘길 시작점(제안) |
|---|---|---|
| 자세히 (기본) | 처음이에요. 모든 안내를 자세히 들을게요. | 상세 안내부터 |
| 보통 | 조금 익숙해요. 처음만 자세히, 반복되면 짧게. | 한 문장 안내부터 |
| 간단히 | 익숙해요. 필요할 때 물어볼게요. | 요청할 때만 |

| 동작 | 상태 | 근거 |
|---|---|---|
| 레벨을 고르고 저장, 홈에 "안내: 보통"처럼 표시 | 구현 | `1-parked-no-warning.png` |
| 다른 기능이 레벨을 읽는 창구(`UserSettingsReader`) | 구현 | 홈이 이 창구로 읽음 |
| 레벨에 따라 안내가 줄어듦(E1), 연습 깊이가 달라짐(A5) | 설계 | 이번 범위 밖. 레벨만 저장·공개하고, E1·A5는 아직 읽지 않음 |
| 경고 안내(C1)는 레벨과 관계없이 줄이지 않음 | 구현 | C1은 레벨을 읽지 않음 |

## 4. 위치 사용 동의

순서는 **앱 안 동의 → Android 위치 권한 요청**입니다. 동의하지 않아도 앱은 그대로 쓸 수 있습니다.

| 동작 | 상태 | 근거 |
|---|---|---|
| [동의해요]를 누르면 시스템 위치 권한 창이 뜸("앱 사용 중에만 허용" / "허용 안함") | 구현 | `h4-location-dialog.png` |
| 허용: 요약과 홈에 "위치 사용: 켜짐" | 구현 | `h4-allowed.png`, `h4-home-after-allow.png` |
| 허용 안함: "위치 권한이 꺼져 있어요. 차량 설정에서 켤 수 있어요." 한 줄을 보여 주고 다음 단계로 넘어감. 다시 묻지 않음. 홈에 "위치 사용: 권한 꺼짐" | 구현 | `h4-denied.png` |
| [나중에 할게요]: 권한 창 없이 넘어감. 홈에 "위치 사용: 꺼짐" | 구현 | `6a-summary-declined.png` |
| 주행 중에는 권한 창을 띄우지 않고 정차할 때까지 미룸 | 설계 | 단위 테스트만 |
| 위치를 쓰는 안내(B1 주차, B2 톨게이트)가 동의 상태를 읽어, 꺼져 있으면 위치 없이 동작 | 설계 | 동의 상태는 저장·공개됨. B1·B2가 아직 구현 전 |

확인이 필요한 것: "위치를 저장하거나 밖으로 보내지 않아요" 같은 문장은 B1·B2 담당과 사실 확인 전이라 화면에 넣지 않았습니다.

## 5. 홈

**정차 중** (위에서 아래로)

1. "정차 중" + 오른쪽에 "안내: 자세히"
2. 처음 설정 카드: 첫 실행을 마치지 않았을 때만. [시작하기]
3. 경고 카드: 경고가 켜져 있을 때만. 경고등 아이콘 + "타이어 공기압 경고 · 주의" + [자세히 보기] → C1 경고
4. 미러 카드(주 버튼): "출발 전에 미러를 맞춰 보세요" [미러 맞추기]
5. 조작 연습 카드: [연습하기]
6. 차량 상태: 기어, 상향등(값의 출처 표시)
7. 내 설정: 위치 사용(켜짐 / 꺼짐 / 권한 꺼짐), 안내 깊이, [바꾸기]

**주행 중**

- "주행 중" + "안내는 음성으로 드려요. 운전에 집중하세요."
- 경고가 켜져 있으면 카드 한 장: 심각도, 경고 이름, 한 문장 조치(예: "급정지하지 말고 다음 휴게소나 목적지에서 점검해 주세요.")
- 버튼·스크롤·애니메이션 없음

| 동작 | 상태 | 근거 |
|---|---|---|
| 정차 중 화면(경고 없음) | 구현 | `1-parked-no-warning.png` |
| 처음 설정 카드와 [시작하기] | 구현 | `6b-first-run-card.png` |
| [미러 맞추기], [연습하기], [바꾸기], [자세히 보기]가 각 화면을 엶 | 구현 | 에뮬레이터에서 눌러 확인 |
| 내 설정 요약의 세 가지 위치 상태 | 구현 | `h4-home-after-allow.png`, `6a-summary-declined.png`, `1-parked-no-warning.png` |
| 정차 중 경고 카드(공기압) | 시연용 신호 | `2-parked-tpms.png` |
| 주행 중 화면, 주행 중 경고 카드 | 시연용 신호 | `3-driving-tpms.png`, `4-driving-no-warning.png` |
| 실제 신호(Virtual Console)로 켠 경고와 기어가 홈에 반영됨 | 설계 | 홈은 C1과 같은 포트를 읽음. C1 화면에서는 확인됐고 홈에서는 미확인 |
| 공기압 외 경고의 아이콘(⚠ 기호) | 설계 | 미확인 |
| 세로 화면, 야간 배색 | 설계 | 미확인. 가로에서는 4·5번을 나란히, 세로에서는 위아래로 쌓도록 만듦 |

## 6. 앱 아이콘

| 항목 | 상태 | 근거 |
|---|---|---|
| 런처 아이콘: 밝은 모래색 바탕, 현대블루 도로, 멀어질수록 짧아지는 흰 차선 네 개, 앞쪽 액티브블루 점 | 구현 | 에뮬레이터 앱 목록에서 확인 |
| 같은 그림을 첫 실행 1/3 화면 머리에 사용 | 구현 | `6c-onboarding-step1.png` |
| 테마 아이콘(단색) 층 | 설계 | 에뮬레이터 런처가 테마 아이콘을 쓰는지 미확인 |

팀 지정 색만 썼고, 바탕이 밝아 어두운 차량 화면에서 눈에 띕니다.

## 7. 디자인 룰 적용

- 색: 팀 지정 다섯 색의 테마 값만 사용. 경고등 아이콘만 C1의 심각도 색(주의 주황, 위험 빨강)을 그대로 씀.
- 액티브블루는 선택 테두리와 진행 표시에만 쓰고, 밝은 바탕 위 글자·아이콘 색으로는 쓰지 않음.
- 선택과 상태는 색 + 기호 + 글자로 함께 표시.
- 글자 대비: 밝은 배색에서 모든 글자 12.5:1 이상. 아이콘은 주의(주황) 3.1:1로 가장 낮고, 옆에 경고 이름을 검정 글자로 함께 둠.
- 글꼴: 앱 공용 테마를 그대로 따름. 현재 테마에 현대산즈·Asta Sans가 설정돼 있지 않아 기본 글꼴로 보임(공용 테마 변경 필요, 이번 범위 밖).

## 8. 팀 결정이 필요한 것

1. 안내 깊이 3단계와 이름(자세히·보통·간단히)을 확정할지.
2. 레벨을 E1·A5가 어떻게 쓸지(3장 표의 "시작점" 제안).
3. 위치 동의 화면에 "저장·전송하지 않는다"는 문장을 넣을 수 있는지(B1·B2 담당 확인).
4. 왼쪽 탭 줄 글자가 다른 화면보다 작게 보임. 키우려면 공용 파일 변경이 필요(후와 협의).
