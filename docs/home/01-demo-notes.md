# 홈 · 첫 실행 시연 메모

2026-11-13 기준. Pleos Connect 에뮬레이터 v2.1.0, debug 빌드, 브랜치 `jaegyoon/home-firstrun`.
아래 순서는 모두 에뮬레이터에서 직접 해 본 것입니다. adb는 `~/Library/Android/sdk/platform-tools/adb -s emulator-5554`를 씁니다.

## 1. 첫 실행을 처음 상태로 되돌리기

두 가지 방법이 있습니다. 시연 영상에는 **방법 B**를 씁니다(시스템 권한 창까지 처음처럼 나옴).

**방법 A. 앱 안에서 (권한은 그대로)**

1. 왼쪽 탭에서 **첫 실행**을 엽니다.
2. 화면을 아래로 내려 **처음 설정 다시 하기**를 누릅니다(debug 빌드에만 있음).
3. 완료 여부, 위치 동의, 안내 깊이가 모두 처음 값(미완료, 묻지 않음, 자세히)으로 돌아갑니다.

Android 위치 권한은 바뀌지 않습니다. 이미 허용했다면 [동의해요]를 눌러도 권한 창 없이 넘어가고, 두 번 거부했다면 창이 다시 뜨지 않습니다.

**방법 B. 새로 설치 (권한까지 처음으로)**

```
adb uninstall com.mirae.chageunchageun
adb install app/build/outputs/apk/debug/app-debug.apk
```

## 2. 시나리오 1 녹화: 앱 실행 → 첫 실행 → 미러 안내

**준비**

1. 방법 B로 새로 설치합니다.
2. 차량이 정차 상태인지 확인합니다: 에뮬레이터 왼쪽 위 기어가 **P**. Virtual Console을 쓰고 있었다면 `python3 tools/console/console.py gear P`.
3. 앱이 실행 중이 아니어야 합니다. 새로 설치한 직후면 그대로 두면 됩니다. 아니면 `adb shell am force-stop com.mirae.chageunchageun`.

**녹화 순서**

| 순서 | 조작 | 화면에 보이는 것 |
|---|---|---|
| 1 | 에뮬레이터 앱 목록에서 **차근차근**(도로 아이콘)을 누름 | 몇 초 안에 **첫 실행 1/3**: 앱 마크, "위치 정보를 사용할까요?" |
| 2 | **동의해요** | 시스템 창 "차근차근에서 이 기기의 위치 정보에 액세스하도록 허용하시겠습니까?" |
| 3 | **앱 사용 중에만 허용** | **2/3** "안내를 얼마나 자세히 들을까요?", 자세히가 선택돼 있음 |
| 4 | (원하면 다른 단계를 고르고) **다음** | **3/3** "준비됐어요", 위치 사용: 켜짐 · 안내 깊이 |
| 5 | **미러부터 맞춰볼까요?** | **미러 맞추기** 1/5 화면 |

**주의**

- 첫 실행 화면으로 자동으로 넘어가는 것은 앱을 켠 뒤 **한 번뿐**이고, 켠 직후 3초 안에 정차가 확인될 때만입니다. 앱이 홈에서 시작했다면 홈의 **처음 설정을 마쳐 주세요 → 시작하기**로 들어가거나, 앱을 종료하고 다시 켭니다.
- 기어가 D인 채로 앱을 켜면 홈의 "주행 중" 화면에 머뭅니다(정상 동작). 기어를 P로 바꾸면 홈에 처음 설정 카드가 보입니다.
- 3/3에서 왼쪽 탭으로 나가면 첫 실행이 완료되지 않습니다. 두 버튼 중 하나를 눌러 끝냅니다.
- 녹화 중 **디버그 → 모두 가짜**는 누르지 않습니다. 누르면 기어·경고가 Virtual Console을 따르지 않습니다.

## 3. 홈 화면 장면

Virtual Console(실제 신호)로 만드는 방법입니다. 먼저 `adb forward tcp:8088 tcp:8088`을 실행하고 브라우저에서 `http://127.0.0.1:8088`을 열어 둡니다(닫으면 명령이 적용되지 않음).

| 장면 | 명령 | 홈에 보이는 것 |
|---|---|---|
| 정차 중, 경고 없음 | `python3 tools/console/console.py gear P` | 미러 카드, 조작 연습 카드, 기어·상향등, 내 설정 |
| 정차 중, 공기압 경고 | `python3 tools/console/console.py telltale TPMS On` | 주황 경고등 + "타이어 공기압 경고 · 주의" + 자세히 보기 |
| 주행 중 | `python3 tools/console/console.py gear D` | "주행 중", "안내는 음성으로 드려요. 운전에 집중하세요." (경고가 켜져 있으면 경고 카드 한 장) |
| 끝낸 뒤 | `telltale TPMS Off`, `gear P` | |

정차 중 공기압 경고와 기어 D 상태의 홈은 Virtual Console로 확인했습니다. 주행 중 경고 카드는 디버그 패널의 가짜 차량(디버그 → 모두 가짜 → 기어 D, 경고 TIRE_PRESSURE)으로만 확인했습니다.

## 4. 그 밖에 확인한 것과 못 한 것

- 위치 권한을 거부하면 2/3 화면 위에 "위치 권한이 꺼져 있어요. 차량 설정에서 켤 수 있어요."가 보이고 그대로 진행됩니다. 홈에는 "위치 사용: 권한 꺼짐"으로 나옵니다.
- **나중에 할게요**를 누르면 권한 창 없이 넘어가고 홈에 "위치 사용: 꺼짐"으로 나옵니다.
- 첫 실행 도중 주행이 시작되면 "정차하면 처음 설정을 이어서 할게요."만 보이고, 정차하면 같은 단계와 선택으로 돌아옵니다(가짜 차량으로 확인).
- 야간 배색에서 홈과 첫 실행이 깨지지 않는 것을 확인했습니다.
- 못 한 것: 세로 화면(이 에뮬레이터에서 앱을 세로로 다시 배치할 수 없었음), 주행 중에 권한 요청이 미뤄지는 것(단위 테스트만).
